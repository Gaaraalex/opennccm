Confiar en el certificado de OpenNCCM

Este servidor usa un certificado HTTPS emitido por su propia autoridad certificadora («OpenNCCM CA»), creada al instalarlo. Mientras su equipo no la conozca, el navegador muestra «No es seguro» y, por eso mismo, no ofrece guardar el usuario y la contraseña. Instálela una vez en cada equipo desde el que use OpenNCCM:

Windows (Chrome, Edge)

  1. Abra el archivo descargado y pulse Instalar certificado…
  2. Elija Equipo local (o «Usuario actual» si no es administrador del PC) y pulse Siguiente.
  3. Marque Colocar todos los certificados en el siguiente almacén → Examinar → Entidades de certificación raíz de confianza.
  4. Siguiente → Finalizar → Sí. Cierre y vuelva a abrir el navegador.

macOS (Safari, Chrome)

  1. Abra el archivo: se agrega al llavero. Elija el llavero Sistema.
  2. En «Acceso a Llaveros», haga doble clic en «OpenNCCM CA» → Confiar → Confiar siempre.

Firefox (cualquier sistema)

  1. Ajustes → Privacidad y seguridad → Certificados → Ver certificados → Autoridades → Importar.
  2. Elija el archivo y marque «Confiar en esta CA para identificar sitios web».

Linux

sudo cp OpenNCCM-CA.crt /usr/local/share/ca-certificates/ && sudo update-ca-certificates

Chrome en Linux usa su propio almacén: chrome://certificate-manager → Autoridades → Importar.

Android e iPhone

  • Android: Ajustes → Seguridad → Más ajustes → Cifrado y credenciales → Instalar certificado → Certificado de CA.
  • iPhone/iPad: abra el archivo en Safari → Ajustes → Perfil descargado → Instalar; luego Ajustes → General → Información → Ajustes de confianza de certificados → active «OpenNCCM CA».

Después

Entre a OpenNCCM con la misma dirección con la que se instaló (por ejemplo https://{{ request.url.hostname }}/). El candado aparecerá sin avisos y, al ingresar, el navegador ofrecerá guardar el usuario y la contraseña.

Alternativas: con un nombre de dominio público puede usar Let's Encrypt, o instalar el certificado de su empresa (sudo bash /opt/opennccm/install.sh → Acceso web).
